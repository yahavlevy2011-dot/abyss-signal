Replaces V1.0.5 after a reported three-player regression. Update every player AND host together.

Fixes repeated hatch state packets, rejects uninitialized identities, prevents duplicate relays and batches terminal output in a bounded queue. Missing sound sources no longer throw repeated errors. V1.0.5 cinematic movement changes have been rolled back.

213 automated tests passed, including simulated three-sender packet and log floods. Actual launcher startup, terminal command response, server shutdown and launcher reopening were checked. One game client joined an isolated world, reached the Lifepod and returned to the main menu after server shutdown. These checks do not certify all three-player gameplay.

Saved worlds remain in place. Full entry-animation alignment, residual Cyclops jitter, adult Sea Emperor spawning and other previously documented gameplay limitations remain open.
